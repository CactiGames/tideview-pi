# What's new in TideView for Raspberry Pi

## 2026.11.23.3

The surf score now matches the tablet's: the big height is the set face at the beach (chop blowing out to sea no longer counts), the score follows MetService's surf page, and the airport's wind shows under the forecast wind. Settings adds wind in knots.

## 2026.11.23.2

Settings > This Pi > Touch screen now warns if the touch screen keeps dropping out, which means the screen needs its own power.

## 2026.11.23.1

First version that updates itself. Settings now shows the version, and has Check for updates now.
